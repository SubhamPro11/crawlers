# Crawlers - AI Tool & Bot Directory Platform

This is a Next.js App Router project for the **Crawlers** directory, which helps users discover AI tools and bots based on use cases.

## Tech Stack
- **Frontend**: Next.js 16.2.10 (App Router), Tailwind CSS v4, TypeScript
- **State Management**: Local mock database (`src/data/mockDb.ts`) with `localStorage` client-side sync.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
